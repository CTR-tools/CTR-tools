# CTR-tool command line suite

This folder contains various command line tools, focused on a specific task:
* bigtool - extract/build BIGFILE.BIG
* model_reader - extract models from LEV, CTR or MPK files
* howl - extract sounds/music from KART.HWL
* lang - extract/build localization files

## Additional tools
* bash_dat - mainly Crash Bash data file extraction tool. For proper models extraction refer to Redhot's repo https://github.com/mateusfavarin/crashbash
